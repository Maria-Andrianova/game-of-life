# Игра «Жизнь»

Курсовой проект: симулятор клеточного автомата Джона Конвея на Java (Swing).

## Возможности

- управление игрой командами из консоли
- поле отображается в графическом окне Swing, размер поля задаёт пользователь
- края поля замкнуты: верхняя граница продолжает нижнюю, левая правую
- начальная колония загружается из текстового файла (`1` — живая клетка, `0` — мёртвая)
- игра завершается в трёх случаях: на поле не осталось живых клеток, конфигурация повторила одну из прежних, ни одна клетка не изменила состояние

## Структура

- `src/Main` — запуск, диалог с пользователем, цикл игры
- `src/Field` — поле и загрузка фигуры из файла
- `src/Cell` — клетка
- `src/Evolution` — шаг эволюции по правилам Конвея
- `src/GameCompletion` — проверка условий завершения
- `src/GraphicWindow` — окно Swing
- `test-figures/` — примеры начальных фигур (`glider.txt` — планер, `t-shape.txt`)
- `tests/Tester.java` — JUnit-тесты
- `docs/` — отчёт о курсовом проекте: описание игры и её правил, постановка задачи, требования к программе и реализация на Java с использованием объектно-ориентированного подхода.

## Запуск

Самый простой способ: скачать репозиторий, открыть проект в IntelliJ IDEA и запустить класс `Main`.

Если IntelliJ IDEA нет, игру можно запустить из командной строки. Для этого нужен установленный JDK:

1. Скачать репозиторий или склонировать его.
2. Открыть командную строку в папке проекта.
3. Ввести по очереди команды:

        cd src
        javac *.java
        java Main

Программа спросит размер поля, путь к файлу с фигурой (например, `../test-figures/glider.txt`) и позицию фигуры на поле. Дальше игра идёт по шагам: каждое нажатие Enter выполняет один шаг, для выхода нужно ввести `выход`. Чтобы завершить работу программы, нужно закрыть графическое окно.

## Тесты

В `tests/Tester.java` собраны 20 тестов JUnit. Они проверяют создание поля и клеток, загрузку фигур из файла (в том числе за краем поля), правила эволюции (рождение, гибель от одиночества и перенаселённости, выживание клетки), все три условия завершения игры и отрисовку окна.

Тесты запускаются из IntelliJ IDEA, нужны JUnit 4 и JUnit 5.
